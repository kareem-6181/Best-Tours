# ✈️ Best Tours
### Discover the World. Experience the Journey.

**Best Tours** is a modern, visually immersive travel website designed to showcase travel destinations and experiences through an elegant interface, cinematic animations, and a smooth browsing experience.

The project focuses on combining premium visual design with interactive elements to create an engaging digital experience for travelers.

---

## 🌍 Overview

Best Tours is a travel company website featuring a modern layout, carefully designed sections, interactive destination cards, and a cinematic landing experience.

The website provides visitors with an intuitive way to explore destinations, discover travel experiences, learn about the company, and get in touch.

---

## ✨ Features

- **Cinematic Intro Animation** — An animated airplane introduction that creates an engaging first impression.
- **Interactive Hero Slider** — Dynamic hero slides with background images and smooth transitions.
- **Modern Navigation Bar** — A clean navigation layout with separate pill-shaped elements.
- **Multilingual Interface** — Arabic and English language support.
- **Light & Dark Themes** — Switch between light and dark appearance modes.
- **About Section** — Introduces the company and its services.
- **Destinations Showcase** — An interactive carousel highlighting travel destinations.
- **Travel Experiences** — A dedicated section presenting different travel experiences.
- **Contact Section** — Provides contact information and social media links.
- **Responsive Design** — Layout adjustments for different screen sizes.
- **Smooth Animations** — Carefully designed transitions and reveal effects.

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone YOUR_REPOSITORY_URL
```

### 2. Open the Project

Navigate to the project directory:

```bash
cd "Best Tours"
```

### 3. Run the Website

Open `index.html` in your browser.

For the best development experience, you can use the **Live Server** extension in Visual Studio Code.
